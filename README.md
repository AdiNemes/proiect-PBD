# Aplicație pentru Evidența și Gestiunea unui Service Auto
**Proiect Baze de Date**

## Scop
Proiectarea unei baze de date pentru gestionarea eficientă a clienților, autovehiculelor, reparațiilor, programărilor și a stocurilor de piese dintr-un atelier auto.

## Obiective
Sistemul va permite operații de adăugare, actualizare, ștergere și vizualizare (CRUD) pentru entitățile principale, oferind trasabilitatea intervențiilor și a costurilor.

## Structura Proiectului
- `docs/`: Documentația proiectului (Word, prezentări)
- `db/`: Scripturi SQL și diagrame
- `app/`: Aplicația practică conectată la BD
- `teste/`: Scripturi pentru testarea constrângerilor
